# Feline Detector (Public Collaboration Copy)

A Flutter app for cat-focused detection and classification workflows.

## Project Status

This repository is the public collaboration copy of the project.

## Requirements

- Flutter SDK (stable channel)
- Dart SDK (bundled with Flutter)
- Android Studio or VS Code with Flutter extensions
- A physical Android device or emulator

## Quick Start

1. Clone the repository.
2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

## Collaboration flow

1. Create a branch from `main`.
2. Keep PRs focused and small.
3. Include testing notes in every PR.
4. Request review before merge.

## Quality Checks

Run these before opening a PR:

```bash
flutter analyze
flutter test
```
